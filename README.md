# Сайт курсу «Машинне навчання»

**Опубліковано: https://kudgey.github.io/ml-course/**

HTML-версія курсу: 14 лекцій, 567 розділів, 307 ілюстрацій, 16 інтерактивних
вставок. Збирається з тих самих markdown-джерел, що йдуть у Gamma, — джерело
правди одне. Кожен пуш у `main` перескладає сайт автоматично.

## Як відкрити

Двічі клацніть **`Відкрити курс.command`**. Він підніме локальний сервер і
відкриє браузер. Інтернет не потрібен: усі схеми, шрифти й формули лежать поруч
зі сторінками.

Перший запуск встановлює залежності — це кілька хвилин і потрібно один раз.
Потрібен [Node.js](https://nodejs.org) (версія LTS).

Закриття вікна Терміналу зупиняє сервер.

## Що вміє сайт

- **Сторінка на лекцію.** Зліва — список лекцій за блоками курсу, справа —
  зміст поточної сторінки, вгорі — пошук по всьому курсу (⌘K).
- **Режим презентації** — клавіша <kbd>P</kbd> або кнопка внизу праворуч:
  більший кегль, сховані бічні панелі, контент на всю ширину. Для проєктора.
- **Клік по ілюстрації** відкриває її на весь екран, <kbd>Esc</kbd> закриває.
- **Темна тема** — перемикач у шапці.
- **Формули** відрендерені у SVG на етапі складання: не залежать від жодної
  зовнішньої бібліотеки й не «стрибають» при завантаженні.
- **Фактичний вивід коду.** Під блоками, які можна виконати автономно, стоїть
  реальний результат запуску з позначкою «код запущено локально, вивід не
  редагувався».
- **Інтерактивні вставки** — шістнадцять штук, щонайменше одна в кожній лекції.
  Кожна рахує за тією самою формулою і на тих самих числах, що стоять у тексті
  поруч, тому працює як перевірка матеріалу, а не як прикраса.
- **Матеріали до розділу** — 114 посилань на першоджерела, документацію та
  інтерактивні демо, розставлені поруч із темою, а не загальним списком у кінці.

## Як вносити правки

Правити треба **джерела**, а не файли в `lectures/` — вони генеруються й будуть
перезаписані.

```bash
# 1. відредагувати джерело лекції
open ../v2/decks/lec05.md

# 2. перевірити його валідатором курсу
python3 ../v2/check_deck.py ../v2/decks/lec05.md

# 3. пересобрати сторінки
python3 ../tools/build_site.py 05        # або без аргументів — усі 14

# 4. подивитися
npm run dev
```

Далі просто закрийте й відкрийте `Відкрити курс.command` — він сам помітить,
що сторінки новіші за збірку, і пересобере.

.vitepress/data/            дані для інтерактивних вставок

Інструменти складання лежать поруч, у `../tools/`:

| Скрипт | Що робить |
|---|---|
| `build_site.py` | джерела лекцій → сторінки сайту |
| `fetch_images.py` | збирає всі ілюстрації локально, пише `extmap.json` |
| `run_examples.py` | виконує приклади коду, пише `outputs.json` |

## Публікація в інтернеті

Сайт уже опублікований: **https://kudgey.github.io/ml-course/**

Складання відбувається само при кожному пуші в `main`
(`.github/workflows/deploy.yml`). Стан останнього запуску — `gh run list`.

Змінна `BASE` у workflow робить збірку придатною для адреси в підкаталозі
`kudgey.github.io/ml-course/`. Якщо колись з'явиться власний домен, її треба
прибрати з workflow, інакше всі шляхи поїдуть.

## Дрібниці, про які варто знати

- **Відкривати `index.html` подвійним кліком не можна** — сторінки не
  перемикатимуться. Потрібен локальний сервер, тобто лаунчер.
- `node_modules` помічено як ігнорований для Dropbox
  (`xattr -w com.dropbox.ignored 1 node_modules`), щоб 130 МБ дрібних файлів
  не синхронізувалися.
- Ілюстрації із зовнішніх джерел збережено локально навмисно: сайт не залежить
  від того, чи живі чужі посилання. Підпис із посиланням на першоджерело
  лишається під кожною такою схемою.
